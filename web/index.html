    这是个前端原型

    完整流程:选城市 → 看全城三维地图 → 定天数偏好 → 生成 → 编辑 → 看路线。 城市精确到市,搜索或按地区选都行。

    选完城市先进「全城」页:这座城的候选景点全部标在三维底图上,标记按类型上色, 可按类型过滤、点榜单定位。定好天数再生成行程。

    右上角的徽标显示数据来源。启动本地后端后徽标变成 真实数据, 此时景点来自高德 POI(每城约 100 个)、建议来自大模型;没接后端时只有 成都 / 杭州 / 西安 三座城有内置数据。

    启动后端:
    cd server
    pip install -r requirements.txt
    uvicorn app:app --reload

    地图是腾讯地图 GL JS 的三维实景底图。在预览里打开走内置密钥代理;自己起服务访问需要在 .env 填 TMAP_KEY,否则退回手画的点位示意图。
